# FaultLine AI Base44 Brand Asset Pack

A production-ready asset bundle for the FaultLine AI Vite/Base44 system.

## Included

- 8 logo lockups in SVG and PNG sizes
- 7 monogram and app-icon variants
- Favicons from 16px through 512px
- Apple touch and PWA maskable icons
- 40 navigation and business-intelligence icons
- Each icon as SVG plus black, gold, and white PNG fallbacks
- 1200×630 social preview
- CSS, JSON, and Tailwind design tokens
- Base44 asset import prompt
- Asset and icon manifests

## Base44

Upload this ZIP with the main FaultLine AI Vite package. Paste `base44/BASE44_ASSET_IMPORT_PROMPT.md` after Base44 has unpacked the archive.

## Preferred files

- Public header: `logos/svg/logo-horizontal-dark-transparent.svg`
- Dark surfaces: `logos/svg/logo-horizontal-light-transparent.svg`
- Compact app mark: `monogram/svg/monogram-gold-black-transparent.svg`
- Favicon: `favicons/favicon.svg`
- Social preview: `social/og-image-1200x630.png`
- App icons: `icons/svg/*.svg`
