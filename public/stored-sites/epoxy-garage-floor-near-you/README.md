# Epoxy Garage Floor Near You — Stored Clone

This is the cloned "epoxy garage floor near you" website, stored in the repo
for reference and version control. It is **not routed or visible** in the
Xtreme AI Systems app.

## Contents

Place the unzipped clone files in this directory (`index.html`, `assets/`, etc.).

## Viewing

Open `index.html` directly in a browser — it is a static clone and runs
without the React app or any backend.

## Why stored, not live

The clone is kept for reference and as a source of design/structure patterns
for original Toolio products. It is intentionally not exposed in the app UI.
