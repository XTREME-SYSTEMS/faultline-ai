# Stored Cloned Sites

This directory holds cloned website builds that are stored in the repo (via git)
but are **not visible or routed** in the Xtreme AI Systems app UI.

## epoxy-garage-floor-near-you/

The cloned "epoxy garage floor near you" site. Stored here as a zipped archive
so it is version-controlled in git, but intentionally not linked from any page
or route in the app.

To serve it locally for reference, unzip and open `index.html` directly in a
browser — it is a static clone and does not require the React app to run.
