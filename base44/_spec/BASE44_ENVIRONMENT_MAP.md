# Base44 Environment Map

## Client safe
`VITE_APP_URL`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`, `VITE_STRIPE_PUBLISHABLE_KEY`

## Server only
`SUPABASE_SERVICE_ROLE_KEY`, `AI_GATEWAY_API_KEY`, `CRON_SECRET`, `WORKFLOW_SECRET`, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `GOOGLE_DRIVE_FOLDER_ID`, `GOOGLE_CHAT_WEBHOOK_URL`

Never expose server-only values in Base44 client code.
