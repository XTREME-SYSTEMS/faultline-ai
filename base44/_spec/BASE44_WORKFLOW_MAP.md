# Base44 Workflow Map

## Audit
Scope → source approval → evidence collection → extraction → findings → Evidence and QA → human review → approve, reject, or dispute → report.

## Repair
Approved finding → priority → repair action → owner → due date → completion evidence → validation → resolved or reopened.

## Outreach
Approved public opportunity → evidence selection → value-first draft → human approval → approved sending adapter → delivery event → reply tracking → opt-out enforcement.

## Monitoring
Five-minute cron → approved rule queue → idempotent lock → bounded checks → event classification → alert or no-op → receipt → retry or dead letter.

## Billing
Test checkout → webhook → idempotency record → entitlement update → billing portal. Live mode stays gated.
