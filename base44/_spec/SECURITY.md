# Security and Responsible Use

- Organization-level RLS on tenant-owned tables
- Least-privilege connector scopes and explicit source allowlists
- Private storage for evidence, client uploads, reports, and outreach evidence
- Human review for material findings
- Evidence provenance, timestamp, confidence, assumptions, and validation state
- Outreach remains draft-only until approval
- No authentication bypass, paywall circumvention, bot-protection evasion, restricted personal-data collection, proprietary-code copying, impersonation, fabricated evidence, public accusations, or public shaming
- Secrets stay server-side and are never committed
- Production actions require explicit approval and receipts
